There is no unified build entry at the root; each submodule starts on its own: `server` runs Express (:3100), `inference_service` runs FastAPI, the desktop installer lives in the `release/` directory (`SmartGarden-Setup-*.exe`), and the optional local basemap scripts `capture_campus_satellite.py` / `make_grid_overlay.py` can be run separately (the big screen defaults to the online tile proxy).
