The repository root carries no runtime code; it serves as the project master plan for phase 6 and later evolution:
- `智慧园林-总体方案.md` defines the five-layer architecture (GIS big screen → business layer → AI engine → data layer → hardware layer) and brings `server` (Express backend), `inference_service` (FastAPI YOLOv8/ONNX inference service), and `delivery_artifacts` (NSIS desktop installer and phased task packages) into a unified product form.
- The AI recognition pipeline is agreed at the root-plan level: the mock inference in `server/src/ai.js` is replaced over HTTP by the standalone FastAPI service, while the result structure (cameraId, category, confidence, bbox, ts) stays unchanged, making the inference capability pluggable with fallback to mock mode.
- The root-level Python scripts `capture_campus_satellite.py` and `make_grid_overlay.py` generate the offline satellite basemap and grid overlay for the GIS big screen; they are the shared data input for `server` and the big-screen frontend. `cesium-mcp-stdio-test.mjs` is used for MCP protocol connectivity verification.
- Each dedicated design document (AI recognition, video surveillance) follows the three-part structure "current-state inventory + design + acceptance metrics" and acts as the constraint source for subsequent development of the server/inference_service/delivery_artifacts submodules.
