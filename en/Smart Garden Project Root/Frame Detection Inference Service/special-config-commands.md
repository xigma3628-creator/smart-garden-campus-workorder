Python 3.11+, installed via `python -m venv .venv && pip install -r requirements.txt`; on Windows set `PYTHONUTF8=1` to avoid GBK log errors; the startup command is `uvicorn app:app --host 127.0.0.1 --port 3101`; on first startup it attempts to auto-download `weights/yolov8n-oiv7.pt` — on mainland-China networks it is recommended to download it manually via gh-proxy into `weights/`; switching to the ONNX backend requires setting `MODEL_BACKEND=onnx` and installing `onnxruntime`.
