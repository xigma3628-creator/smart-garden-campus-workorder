Environment variable conventions: `PORT` (HTTP port, default 3000), `MQTT_PORT` (embedded broker port, default 1883), `FRONTEND_DIST` (frontend static asset directory; when present, enables the `/three.js-demo/digital-farmland` mount), `GARDEN_DATA_DIR` (root directory for SQLite and uploaded files, default `server/data`). In production, `aedes` can be replaced by an external EMQX — only the connection address needs to change.
