Each script runs independently via `node test/<name>.mjs`; the backend under test (default listen port 3100) and the MQTT broker (default `mqtt://127.0.0.1:1883`) must be started first. Target addresses can be overridden with the `API_BASE`, `MQTT_URL`, `WS_URL`, `HEALTH_URL` environment variables; `drone-acceptance.mjs` additionally requires the inference service online at :3101 and depends on two test assets: `butterfly.jpg` and `../../digital-farmland/public/static/35.mp4`.
