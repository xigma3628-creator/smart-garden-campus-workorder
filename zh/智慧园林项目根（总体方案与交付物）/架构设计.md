本仓库根目录不承载运行时代码，而是作为六期及以后演进的项目总纲：
- `智慧园林-总体方案.md` 定义五层架构（GIS大屏→业务层→AI引擎→数据层→硬件层），并把 `server`（Express 后端）、`inference_service`（FastAPI YOLOv8/ONNX 推理服务）、`delivery_artifacts`（NSIS 桌面安装包与分阶段任务包）纳入统一产品形态。
- AI 识别链路在根级方案中约定：`server/src/ai.js` 的模拟推理通过 HTTP 被替换为独立 FastAPI 服务，结果结构（cameraId、category、confidence、bbox、ts）保持不变，实现推理能力可插拔、降级回退到模拟模式。
- 根级 Python 脚本 `capture_campus_satellite.py`、`make_grid_overlay.py` 用于本地底图抓取与网格叠加（可选的演示辅助脚本；大屏默认使用高德在线瓦片代理，不再内置离线卫星底图）；`cesium-mcp-stdio-test.mjs` 用于 MCP 协议连通性验证。
- 各专项方案（AI 识别、视频监控）按“现状盘点 + 设计 + 验收指标”三段式组织，作为 server/inference_service/delivery_artifacts 子模块后续开发的约束来源。
