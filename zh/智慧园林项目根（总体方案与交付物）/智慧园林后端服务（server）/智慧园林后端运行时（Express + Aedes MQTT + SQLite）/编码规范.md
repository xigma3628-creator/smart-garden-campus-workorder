- Express 路由通过工厂函数（如 `createRoutes`、`createUploadsRouter`、`createTreeAssetsRouter`）返回 `Router` 实例，由 `index.js` 集中 `app.use` 挂载，便于分模块加载与测试隔离。
- 对外部子系统（MQTT publish、WebSocket 客户端数、AI 引擎、灌溉引擎）采用 setter 回调注入（`setPublishControl` / `setClientCounter` / `setAi` / `setIrrigation`），避免模块间直接耦合。
- REST 响应统一返回 `{ ok, ...payload }` 结构体，错误分支返回 `{ ok: false, error: '...' }`，健康检查额外包含设备在线数、WS 客户端数与 DB 行数。
- 敏感或写操作路由通过 `requireAuth()` 鉴权中间件保护，读接口则保持公开访问（如知识库、苗木档案列表）。
- 文件上传采用「声明 Content-Type + 魔数双校验」策略（jpeg/png/webp），并在路径读取前做 `path.normalize` + 根前缀校验以防止 `../` 越界。
- 设备元数据从 `devices.json` 初始化到内存 `Map`，运行时通过 `registerDevice` / `updateDeviceMeta` / `unregisterDevice` 动态增删改，确保设备目录与 MQTT 摄取逻辑共享同一份源。
