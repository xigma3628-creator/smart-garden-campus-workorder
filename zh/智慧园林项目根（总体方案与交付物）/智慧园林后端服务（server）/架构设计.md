server 作为 Node.js 应用根，由 `src/index.js` 启动 Express 服务并挂载各业务路由；核心运行时（core_runtime）在进程内维护 MQTT Broker、WebSocket 广播、内存设备状态目录与 SQLite 时序存储，被 drone_simulator、ai_kb、scripts、tests 共同消费。
- 通信契约：HTTP REST 由 `src/routes.js` 汇总暴露；设备遥测与实时事件走 Aedes MQTT 主题（如 `device/...`、`drone/...`），实时画面通过 WebSocket 推送帧；文件上传经 `src/multipart.js` / `src/uploads.js` 落盘后由 AI 推理回调回填结果。
- 数据边界：SQLite 由 `src/db.js` 初始化 schema，所有写操作经由 `state.js` 的内存快照 + 持久化双写；AI 与知识库解耦，摄像头帧先入库再触发 `ai.js` 推理。
- 运行期扩展点：`simulator/simulate.js` 与 `scripts/seed-trees.mjs`、`simulate-drone.mjs` 复用同一套 MQTT 发布接口注入仿真数据；`test/*` 验收脚本通过 HTTP/MQTT/WS 三通道驱动端到端场景。
