模块由三层组成：
- `server/src/drone.js`（数据层）：仅负责 SQLite 建表 (`drone_missions`/`drone_frames`)、行→对象映射 (`toMission`/`toFrame`)、航线规范化 (`normalizeRoute`)、任务编号生成 (`nextMissionNo`) 及图片落盘路径计算 (`DRONE_FRAME_DIR`)；不持有业务状态机。
- `server/src/routers/drone.js`（接口层）：基于 Express Router 暴露 `/api/drone/*` REST 端点，调用 drone.js 的数据方法，并承载任务状态机 (`planned→flying→done/aborted`)、multipart 帧上传、向外部 `/infer` 服务发起推理请求、高置信病虫害触发告警、以及定时补偿重试 (`startDroneInferenceRetry`)。
- `server/simulator/simulate.js`（独立可执行脚本）：通过 mqtt 客户端连接 `mqtt://127.0.0.1:1883`，以 2 秒周期向 `smart-garden/{type}/{id}/status` 发布 16 台设备的仿真遥测，支持 SIM_FAULT 环境变量注入干旱故障，并订阅灌溉阀门下行控制主题进行双向联动。
依赖方向：router → drone.js → db.js/sqlite；simulator 为独立入口，不与 web 路由耦合。
