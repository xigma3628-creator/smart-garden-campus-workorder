- 测试入口统一以注释行声明用途与用法，并通过 `process.env.X || 'default'` 解析外部依赖地址。
- 用例组织采用「定义 record(name, pass, detail) → 执行动作 → await waitFor(fn, timeout) → record 记录结果」的固定模板。
- HTTP 交互基于原生 `fetch`，认证通过 `Authorization: Bearer <token>` 请求头注入，JSON 响应用 `.json().catch(() => ({}))` 容错解析。
- 等待异步就绪状态统一封装为 `waitFor` 轮询函数，以 `sleep(ms)` 间隔重试直至超时返回 `{ ok, elapsed }`。
- WebSocket 重连逻辑采用指数退避策略（初始 500ms，翻倍上限 2000ms），并在 onopen/onclose 中维护重连次数与健康检查时间戳。
