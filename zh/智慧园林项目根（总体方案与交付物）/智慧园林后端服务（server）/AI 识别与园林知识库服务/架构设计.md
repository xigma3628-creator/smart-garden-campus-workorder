模块由两条并列的服务管线组成，均通过 `server/src/db.js` 直接操作 SQLite：
- AI 识别管线 (`ai.js`)：启动时创建 `ai_results` 表；`createAiEngine` 返回的 `recognize(cameraId, source)` 优先调用 `inferFromModel` 向 `INFERENCE_URL`（默认 `http://127.0.0.1:3101/infer`）发送抓帧请求，失败后自动降级到 `mockInference`；分类映射通过 `classes_map.json` 与内置 `TAXONOMY` 双轨合并，结果统一经 `insertAiResult` 落库并触发告警/广播。
- 知识库管线 (`kb.js`)：维护 `kb_entries` 表及可选 FTS5 `kb_fts`（trigram 分词），支持按 category（tree/pest/maintenance_standard）增删改查；`importEntries` 按 pest→tree→maintenance_standard 顺序导入以解析 `common_pests` 的 id 引用；搜索先走 FTS MATCH，短词或 FTS 不可用时退化 LIKE。
- REST 路由层 (`routers/kb.js`)：基于 Express Router 暴露 `/api/kb/*` 接口，查询类接口无鉴权，写类接口使用 `requireAuth('admin')`；QA 接口先检索 Top-K 参考再调用 `rewriteWithLlm` 生成回答。
依赖方向：router → kb → db；ai → frame-grabber / cameras / state / rules，二者互不耦合。
