所有脚本均为顶层 ESM 入口（.mjs），直接依赖 server/src 中的运行时模块，按职责分为两类：
- 数据播种：import-kb.mjs 通过 ../src/kb.js 的 importEntries/ftsOk 将 garden_kb.json 写入 kb_entries；seed-trees.mjs 以 devices.json 中设备经纬度为锚点，用 mulberry32 固定种子随机数在 tree_assets 表 INSERT OR IGNORE 幂等生成约 60 棵苗木。
- 接口模拟与评测：simulate-drone.mjs 调用 /api/auth/login → /api/drone/missions → ffmpeg 抽帧 → /api/drone/frames 上传并 finish；kb-eval/eval.mjs 从 db 抽取 20 题调用 /api/kb/qa 产出 questions.json 与 eval-report.json，kb-eval/selfcheck.mjs 对 /api/kb/* 做端到端自检。
依赖方向单向：scripts → src/db.js、src/kb.js、src/tree-assets.js，不反向被业务代码引用。配置统一通过 process.env（KB_SEED_FILE、API_BASE、DRONE_BASE/USER/PASS）或命令行参数注入，避免硬编码运行环境。
