- 脚本通过 path.dirname(fileURLToPath(import.meta.url)) 推导 __dirname，再基于相对路径解析跨仓库资源（如 ../../参考项目/...）。
- 外部行为一律通过 process.env 暴露（KB_SEED_FILE、API_BASE、DRONE_BASE/USER/PASS），默认值仅作为 fallback。
- HTTP 调用封装统一的 readJson 辅助函数，根据 res.ok 与 data.ok 抛出包含 status 的错误信息。
- 需要可重复执行的脚本使用固定种子随机数（mulberry32）+ INSERT OR IGNORE 实现幂等播种。
